## Visão geral

League AI Oracle foi um experimento de copiloto estratégico com IA para League of Legends. O projeto explorou como dados de partidas da Riot Games API poderiam apoiar insights contextuais e recomendações de estratégia. O repositório está arquivado e não é apresentado como um serviço ativo.

## Recursos explorados

- Busca de dados de partidas pela Riot Games API
- Recomendações estratégicas assistidas por IA
- Exploração de probabilidade de vitória e desempenho de jogadores
- Análise de confrontos entre campeões

## Stack

- **TypeScript** — Linguagem principal para desenvolvimento com tipagem
- **IA/ML** — Análise e previsões experimentais
- **Riot Games API** — Fonte de dados das partidas do protótipo
